# Каркаси сторінок LifeMap (UI/UX Wireframes)

Файли: `wireframe-1-home.png`, `wireframe-2-interests.png`, `wireframe-3-lifemap.png`, `wireframe-4-matches.png`.

| Сторінка | Елементи | Дії користувача |
|---|---|---|
| 1. Головна | Меню (Головна, Інтереси, Моя LifeMap, Збіги), заголовок, підзаголовок, кнопки «Почати» і «Дивитись збіги», три картки пояснення | Натискає «Почати» або переходить за меню |
| 2. Вибір інтересів | Категорії (Музика, Хобі, Спорт, Кіно і книги, Цілі, Спосіб життя), теги-кнопки, кнопка «Очистити вибір» | Вибирає тег кліком, повторний клік скасовує |
| 3. Моя LifeMap | Список вибраних тегів з ✕, повідомлення для порожньої карти | Прибирає тег кліком, редагує карту |
| 4. Збіги | Картки людей: ім'я, відсоток, спільні теги; повідомлення «Оберіть хоча б один тег» | Переглядає людей від найбільшого відсотка |

## Принципи дизайну

- Основний колір: фіолетовий `#6d28d9`, кнопки: жовтий `#fbbf24`, шрифт Arial.
- Один екран, одна головна дія.
- Адаптація під телефон: меню переноситься, кнопки й теги великі для дотику.
