# LifeMap

Сайт, де користувач обирає теги інтересів і бачить людей з відсотком сумісності (коефіцієнт Жаккара).

## Запуск
Відкрити `index.html` через Live Server у VS Code.

## Структура
- `index.html` — головна сторінка
- `src/style.css` — стилі
- `src/data.js` — теги та тестові профілі
- `src/tags.js` — вибір тегів
- `src/lifemap.js` — карта LifeMap
- `src/storage.js` — збереження (localStorage)
- `src/match.js` — алгоритм Жаккара
- `src/main.js` — з'єднує всі частини
